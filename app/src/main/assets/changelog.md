# 更新日志
本项目在 1.0.0 正式版之前均为开发版（`-dev`）。
版本号格式为 `主版本.次版本.修订号-dev`，遵循 [语义化版本](https://semver.org/lang/zh-CN/)。
最新版本在最上方。

---

## v0.3.6-dev (2026-09-17)

### 新增
- **半屏模型选择器支持管理配置**：输入栏模型选择器右上角新增「管理配置」入口，可直接进入 API 配置页
- **系统提示词**：设置 → 对话中直接编辑，发送时注入对话头部，全局生效

### 优化
- **连接测试信息更完整**：成功结果现在附带模型回复预览，一眼确认模型答非所问还是正常
- **已选模型可直接切换**：API 编辑页已选模型区点击非当前模型即切为当前使用；从可用区添加模型也同时切换
- **模型列表视觉统一**：未选中的模型行不再有底色，只有当前使用的模型才加深背景

### 修复
- **API 配置页换模型不生效**：从可用模型区选择后，实际使用的模型字段未同步更新，现已修复
- **对话总结只反映最后一轮**：改为增量式合并——每轮总结会带上此前的总结生成覆盖全程的概括
- **AI 回复前的空白占位框**：等待首个回复内容时不再渲染空气泡
- **模型列表翻页时按钮跳动**：最后一页不满时补齐占位高度，分页控件位置稳定
- **联网搜索开关实际未生效**：开关值从未读入请求配置，现已接入发送链路
- **长模型名折行**：模型行改为单行省略号，翻页占位高度不再被撑破
- **移除已选模型需要点两次**：行点击只负责切换当前模型，移出列表改为行尾 ✕ 按钮一步完成；当前使用的模型以加深背景加粗标记

### 变更
- 移除全屏模型切换页（已由半屏选择器替代，无导航入口）
- API 配置列表改用单选样式：圆点标生效、整行点击切换、行尾铅笔进编辑，去掉叠加的背景高亮与多重对勾
- API 配置编辑页拆分：模型名称、拉取列表、已选模型挑选整体移入「模型管理」二级页，编辑页只留基本信息；提供商选择由三行单选改为下拉一行，页面长度大幅缩短
- 流式输出滚动改为智能跟随：默认贴底跟进，手动上滑即停（不再被拽回底部，可自由回看历史），滚回底部自动恢复；发送新消息强制回底；修复视口被钉在消息开头、新增内容在屏幕外的问题
- 思考程度「关闭」对 Gemini 不生效：2.5 系默认开思考，此前关闭时整个配置不发、沿用模型默认。现在 OFF 显式发送 thinkingBudget = 0（官方关闭值）
- 思考程度说明文案更新：点明 o 系、R1 等推理模型自带思考、无法用此开关关闭

## v0.3.5-dev (2026-09-17)

### 新增
- **模型筛选**：API 编辑页可筛选要显示的模型，输入栏模型切换页只显示已选模型
- **联网搜索**：支持 Gemini 原生联网搜索，在设置页开启后生效
- **API 测试可取消**：测试进行中再次点击立即中断当前测试

### 优化
- **模型切换改为半屏**：点输入栏左下角的模型区改为弹出底部半屏选择器，选模型时仍能看到聊天内容
- **流式输出流畅度**：改为 50ms 批量写入数据库，长回复不再因频繁落盘而卡顿

### 修复
- **无气泡模式下助手思考仍显示气泡**：统一遵守气泡设置
- **输入栏模型切换无反应**：改为原子保存，等待完成后再返回聊天页

### 变更
- **石墨配色移到预设列表最前面**：更适合阅读聊天内容，作为默认配色
- **精简发送状态**：用户消息下方不再显示“发送中”，AI 生成前也不再显示 loading 占位条——进度由输入栏的阶段文字承担
- 版本号更新到 0.3.5-dev (versionCode 27)

## v0.3.4-dev (2026-08-31)

### 新增
- **增强透视**：输入栏透视分成两档。默认只透出背景图，输入的文字始终清晰；开启增强透视后连文字一起半透，能看见输入栏后面的消息

### 变更
- **默认配色改为石墨**：橙色作为品牌色留在图标上就够了，铺满界面过于抢眼——要看的是聊天内容本身。想要彩色仍可自行切换，「品牌橙」改名为「暖橙」，与其他配色的命名一致
- **抽屉不再几乎占满屏幕**：改为占屏宽的八成左右，留出的那一截既能看见背后是聊天页，也可点击关闭
- **思考程度按档位加深颜色**：此前三档同一个颜色，看一眼只知道开着、不知道开到哪档。现在低中高的底色依次加深
- **请求日志显示配置组名称**：此前一律显示提供商标识，同一个提供商下的多组配置（不同中转、不同密钥）区分不出来。记录的是当时的组名快照，事后改名或删除配置组都不影响已有记录

### 修复
- **日志筛选菜单总在最左侧弹出**：菜单的定位锚点原本是整条筛选栏，与点了哪个按钮无关。现在从被点的那个按钮下方弹出

## v0.3.3-dev (2026-08-30)

### 变更
- **输入栏透视改为整块半透**：此前只把底色调透，输入的文字与图标仍然完全不透明，能透上来的只有空白区域。现在整块一起半透，背后压着的内容也看得见
- **下拉菜单圆角放大**：Material 默认 4dp，配上周围 20dp 的设置分组与全圆的下拉按钮显得生硬，改为 20dp

### 修复
- **输入栏那圈边框**：不是刻意加的边框，是 Material 的 Surface 按抬升度叠的一层色调。那层色调不跟着透明，边缘就比里面更实，看着像描边。两个 elevation 都归零后消失
- **透视强度松手时跳一下**：抬手那一刻落盘还没完成，显示权却已交回设置里的旧值，thumb 于是先跳回原位再跳到新位置。改为以「落盘是否追上」为准，与手指在不在滑块上无关

## v0.3.2-dev (2026-08-30)

### 新增
- **请求日志记录提供商与模型**：此前只有主机名，用同一个中转地址的不同模型区分不出来。定位仍靠主机名（能看出请求实际打到了哪里），筛选按提供商与模型
- **成功的请求也保留**：此前只有失败记录会存下来，重启后就查不到「昨天那次为什么慢」「上周用的是哪个模型」
- **日志筛选**：可按时间、模型、提供商、只看失败四个维度叠加筛选。时间按「距今多久」分组而非日历日期——排查时的问法是「今天出的」或「前几天那次」，很少精确到某月某日
- **日志删除**：可删单条，也可一次删掉当前筛选出的全部。筛出某个模型的所有失败再一并清掉，比逐条删实用
- **日志记录开关**：默认开启，关闭后不再记录新的请求，已有记录保留
- **日志保留时长**：默认一直保留，只在手动删除时清除。也可选按 1 天 / 7 天 / 30 天自动过期。改完立刻按新策略清理，不必等下次启动
- **输入栏透视强度可调**：原先透明是固定的一档，现在可以调「透多少」
- **输入栏悬浮样式**：可选四周留出间距、四角全圆的悬浮式，或保持原来铺满底部的通栏式
- **日志长按多选**：长按任一条进入多选，可逐条勾选或全选当前筛选结果，一次删除。多选时按返回先退出多选而不是离开页面

### 变更
- **设置里的滑块改为松手才保存**：拖动过程中预览实时跟着变，抬手时才写入。此前每移动一点就写一次磁盘，滑块跟不上手指
- **裁剪改为直接拖框**：不再用四条边各一个滑块，而是在预览图上拖动方框的边或四角，按住框内可整体移动。框线、三分线与四角把手让边界位置一眼可见
- **日志页说明文案更新**：此前写着「失败记录会保留到下次启动，成功记录仅存于本次运行」，与现在的行为已不符

### 修复
- **裁剪边缘难拖**：框贴到图片边缘时把手有一半在图片之外，此前那一半点不到。现在手势区比图片大一圈
- **裁剪第一次拖动没反应**：初始框占满整张图，落在中间会判为整体平移，而此时无处可移，于是什么都不动，看起来像「要拖两次」。现在初始框四周留有内缩
- **模糊强度在 0% 与 1% 之间闪烁**：缓存键此前含「当前有没有模糊」，跨过这个界限时整张图会重新解码
- **调模糊时预览卡顿**：模糊改在绘制层做，图片只解码一次，拖动过程中每帧不再重新解码（Android 12 及以上走 GPU）
- **模糊强度整体调弱**：原先 20% 就已经很糊，现在低段变化平缓，满强度仍有足够力度
- **裁剪遮罩与图片对不上**：预览框此前固定 16:9，竖幅图只占中间一条，压暗的是两侧留白而非图片本身
- **裁剪不再有丢图风险**：此前直接覆盖原文件，压缩失败图片就永久丢失。现在先写临时文件再替换

## v0.3.1-dev (2026-08-29)

### 新增
- **背景效果可选**：除原有的遮罩外新增模糊，以及两者叠加。遮罩压暗但保留画面细节，模糊抹掉细节但保留色调，图片花哨时模糊更有效
- **背景预览实时反映改动**：调遮罩浓度或模糊强度时，设置页上方的预览立刻跟着变，且与进入聊天后看到的完全一致——两处用的是同一个渲染组件
- **头像模糊**：可让画面复杂的自定义头像不那么抢眼，0% 为不处理。设置页缩略图与聊天里的头像同步生效
- **图片裁剪**：背景与两个头像都可裁剪，四条边各一个滑块，上方预览压暗将被裁掉的部分

### 修复
- **API 配置行右侧点不动**：可点区域此前不含右侧箭头，涟漪也在箭头前就断了。现在整行可点，左侧勾选区仍单独负责切换生效组
- **颜色模式改为下拉选择**：循环点击时点之前看不到有哪些选项，从深色回到跟随系统还要连点两次
- **思考程度面板去掉图标**：一到三个灯泡看着像装饰，而档名本身已经是有序的，下面那行说明也讲清了差别
- **思考图标换回灯泡**，下拉按钮圆角调大以贴合整体风格

## v0.3.0-dev (2026-08-29)

### 变更
- **图标与标题对齐**：消息显示页六项改为钟面、三点面板、标签、柱状图、速度表与秒表；颜色模式配半明半暗圆，动态取色配交叠双圆

- **API 配置列表点整行进入编辑**，左侧勾选区负责切换生效组
- **输入栏不再显示配置组名**：该信息顶栏副标题已有
- **模型列表项固定一行**、过长可左右滑动。此前允许两行导致高度不统一
